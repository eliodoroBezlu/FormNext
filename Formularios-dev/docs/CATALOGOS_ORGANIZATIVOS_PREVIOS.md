# Listas que servían los desplegables antes de usar el maestro

Superintendencia y gerencia se servían de dos listas escritas a mano en
`src/lib/actions/dataSourceService.ts`, sin ninguna relación con el maestro de
Mongo. Al autorrellenar esos campos a partir del área, el valor deducido tenía
que existir en la lista o el desplegable lo rechazaba, así que la lista pasó a
ser la misma que alimenta la deducción: el maestro.

Este archivo queda como **registro de lo que ofrecían** aquellas listas. Sirve
para dos cosas: comprobar que el maestro no se ha quedado corto, y tener de
dónde sacar las entradas que falten si hay que darlas de alta.

No es código ni se consume desde ningún sitio.
